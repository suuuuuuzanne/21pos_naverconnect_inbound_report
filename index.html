인바운드 2차 보고

인바운드 통계 엑셀을 올리면 담당자별 누적, 컨택일자별 데일리로 정리됩니다.

신청일자지역상호업종사업자번호연락처상담결과상담날짜상담시간상담내용

노란 칸(지역·업종·상담날짜·상담시간)은 직접 고칠 수 있고, 이 브라우저에 자동 저장됩니다.

1. 원본 올리기

  1. 인바운드 통계 엑셀(네이버_인바운드_통계_*.xlsx)을 엑셀에서 저장한 상태 그대로 준비합니다. 계산 결과가 들어 있어야 지역·업종이 자동으로 읽힙니다.
  2. 보고서 탭의 점선 칸에 파일을 끌어놓거나 눌러서 선택합니다.
  3. 새 데이터가 쌓이면 같은 방법으로 다시 올립니다. 고친 칸은 신청일시 기준으로 유지됩니다.
엑셀 파일은 GitHub 저장소에 올리지 마세요. 사이트에는 화면 소스만 두고, 데이터는 사용할 때마다 각자 브라우저에서 올립니다. 사업자번호와 연락처가 들어 있습니다.

2. 자동으로 채워지는 항목

항목가져오는 곳
신청일자신청일시의 날짜
지역, 업종원본의 지역(자동), 업종(자동) 열. 비어 있으면 직접 입력
상호상호 열, 없으면 매장명
사업자번호, 연락처, 상담내용원본 그대로
상담결과상담결과 열. 오타(무음답, 구매 예정 등)는 바로잡아 표시
상담날짜1차 컨택일. 부재중·무응답은 재컨택_로그 기준으로 1차·2차·3차를 모두 표시
상담시간1차 컨택일에 시간이 있으면 그 시간, 없으면 상담내용에 적힌 첫 시각(예: 11:47)

담당자가 강빛나(이수진)처럼 괄호가 있으면 괄호 안 이름(이수진)을 실제 담당자로 보고 묶습니다. 담당자가 비어 있으면 미지정으로 모입니다.

3. 정리된 데이터 사용하기

  1. 위쪽에서 담당자를 고르면 그 사람의 전체 누적이 나옵니다. 전체를 누르면 모두 보입니다.
  2. 데일리는 컨택일자별로 묶어서 보여주고, 누적은 날짜순으로 쭉 이어 보여줍니다.
  3. 날짜 선택으로 하루만 골라 보고할 수도 있습니다.
  4. 노란 칸을 채운 뒤 엑셀로 내보내기를 누르면 현재 선택한 범위가 파일로 저장됩니다. 전체 누적 시트와 담당자별 시트(날짜별 구분선 포함)가 만들어집니다.

4. GitHub Pages로 공유하기

  1. GitHub에서 새 저장소를 만듭니다. 예: inbound-report
  2. 이 index.html 한 파일만 올립니다(Add file, Upload files, Commit).
  3. 저장소의 Settings, Pages에서 Source를 Deploy from a branch로, Branch를 main, 폴더를 / (root)로 정하고 Save를 누릅니다.
  4. 1~2분 뒤 https://내아이디.github.io/inbound-report/ 주소가 생깁니다. 이 주소를 팀에 공유하면 됩니다.
  5. 화면을 고치고 싶으면 같은 파일을 다시 올려 덮어씁니다.
