인바운드 2차 보고

엑셀을 올릴 때마다 기존 데이터는 변경분만 반영하고 신규 건은 추가해서 누적합니다.

신청일자지역상호업종사업자번호연락처상담결과1차 컨택일1차 시간2차 일자2차 시간3차 일자3차 시간상담내용

노란 칸(지역·업종·1~3차 일자·시간)은 직접 고칠 수 있고 자동 저장됩니다. 부재·무응답 건은 표 맨 아래에 따로 모았습니다.

0. 구글 시트로 자동 불러오기

  1. 인바운드_통계_구글시트용.xlsx를 구글 드라이브에 올리고 열어서 파일 > Google 스프레드시트로 저장을 누릅니다. 탭은 인바운드_원본, 재컨택_로그, 설정_사용법, 분류사전이 만들어집니다.
  2. 시트 오른쪽 위 공유에서 일반 액세스를 "링크가 있는 모든 사용자", 권한을 "뷰어"로 바꿉니다.
  3. 시트 주소를 복사해 GitHub의 index.html을 연필(편집) 아이콘으로 열고 파일 아래쪽 <script> 부분에 있는 SHEET_URL 줄의 따옴표 안에 붙여넣은 뒤 Commit changes를 누릅니다. (이 사용법 글 속의 같은 글자가 아니라 코드 줄입니다)
  4. 매일 하는 일: 원본 데이터 A~L열을 인바운드_원본 시트 A3부터 값으로 붙여넣기(Ctrl+Shift+V)만 하면 됩니다. 전체 데이터면 덮어쓰고, 새 건만이면 마지막 데이터 아래 빈 줄에 붙입니다. 1~2행과 M열 이후(회색)는 건드리지 마세요.
  5. 자동 계산: 컨택일, 최종 상태, 2·3차 컨택일·시간(상담내용에 쓴 날짜), 2·3차 예정일, 지역·업종. 재컨택_로그는 입력하지 않아도 됩니다.
링크가 있는 모든 사용자에게 공개하면 시트 주소를 아는 사람은 사업자번호와 연락처를 볼 수 있습니다. 공개 저장소의 index.html에도 주소가 들어가므로 팀 밖에 주소가 퍼지지 않게 관리하세요.

1. 매일 업로드하기 (시트를 쓰지 않을 때)

  1. 그날의 인바운드 통계 엑셀(네이버_인바운드_통계_*.xlsx)을 엑셀에서 저장한 상태 그대로 준비합니다. 계산 결과가 들어 있어야 지역·업종이 읽힙니다.
  2. 보고서 탭 위쪽 점선 칸에 파일을 끌어놓거나 눌러서 선택합니다.
  3. 신청일시가 같은 기존 건은 바뀐 내용만 덮어쓰고, 처음 보는 건은 새로 추가됩니다. 이번 엑셀에 없는 예전 건도 그대로 남습니다. 결과는 위쪽에 "신규 N건, 변경 M건"으로 나옵니다.
  4. 재컨택_로그의 날짜도 누적되므로, 로그를 비워도 2차·3차 날짜 기록은 유지됩니다.
누적 데이터는 사용 중인 브라우저에 저장됩니다. 다른 PC나 다른 브라우저, 다른 팀원에게는 따로 보이지 않습니다. 같이 보려면 백업 받기로 파일을 받아 상대방이 백업 불러오기를 누르면 됩니다. 브라우저 방문 기록·사이트 데이터를 지우면 누적분이 사라지니 가끔 백업해 두세요. 엑셀 파일은 GitHub 저장소에 올리지 마세요. 사업자번호와 연락처가 들어 있습니다.

2. 조회하기

  1. 담당자 버튼으로 사람을 고르면 그 사람의 누적 건이 나옵니다. 전체를 누르면 모두 보입니다.
  2. 조회 기간은 두 가지입니다. 신청일자 기준과 1차 컨택일 기준을 각각 달력으로 고르고, 둘 다 걸면 두 조건에 모두 맞는 건만 나옵니다. 각 기간은 최대 31일이고, 비우려면 지우기를 누릅니다. 1차 컨택일이 없는 건은 컨택일 기간을 걸면 빠지니, 함께 보려면 "컨택일 미입력 포함"을 체크하세요.
  3. 결과는 날짜별로 정리되고, 부재·무응답 건은 표 맨 아래 별도 구간에 모입니다.
  4. 상태 버튼(구매, 구매예정, 2차·3차 컨택예정, 보류, 취소, 부재·무응답)은 색이 다르고, 누르면 그 상태만 골라 볼 수 있습니다.

3. 자동으로 채워지는 항목

항목가져오는 곳
신청일자신청일시(날짜와 시각)
지역, 업종원본의 지역(자동), 업종(자동) 열. 비어 있으면 직접 입력
상호상호 열, 없으면 매장명

1차 컨택일·시간, 2차·3차 일자·시간1차는 1차 컨택일(시간 포함)입니다. 2차·3차는 상담내용에 쓴 2차부재(10/19), 3차 부재 10/21 14:30 같은 표기에서 읽고, 없으면 시트의 2·3차 컨택일, 재컨택_로그 순으로 씁니다. 재컨택 예정일만 있으면 "(예정)", 기록이 없으면 "미컨택", 컨택했는데 날짜가 없으면 "일자 미기재"로 나옵니다.

4. 내보내기

엑셀로 내보내기는 지금 조회한 담당자·기간·상태 그대로 저장합니다. 전체 누적 시트와 담당자별 시트가 만들어지고, 각 시트는 날짜별 구분줄 아래 부재·무응답 구간이 따로 붙습니다.

5. GitHub Pages로 공유하기

  1. GitHub에서 새 저장소를 만듭니다. 예: inbound-report (Public)
  2. Add file, Upload files로 index.html 한 파일만 올리고 Commit changes를 누릅니다.
  3. Settings, Pages에서 Deploy from a branch, main, / (root)를 선택하고 Save를 누릅니다.
  4. 1~2분 뒤 생기는 https://내아이디.github.io/inbound-report/ 주소를 팀에 공유합니다.
  5. 화면을 고칠 때는 같은 이름의 파일을 다시 올려 덮어씁니다. 저장된 누적 데이터는 그대로 유지됩니다.
